# saddlepoint-expansions

Saddlepoint expansions of any order for tail probabilities and densities of random vectors,
from the cumulant generating function alone. Python port of the Julia package
[SaddlepointExpansions.jl](https://github.com/s-broda/SaddlepointExpansions.jl).

The package implements the expansions of

> S. A. Broda and R. Kan, *Uniform saddlepoint expansions for multivariate tail probabilities*,

for the orthant probability $P(X \ge x)$ (componentwise) of a random vector $X$ in any
dimension, for its density, and for the density and distribution function of a ratio, together
with the classical univariate expansions (Daniels; Hauschildt and Robinson) as the case $d = 1$.
The first-order term of the multivariate tail expansion is the approximation of Kolassa (2003);
the terms of orders two and higher are new, and their relative error is $O(n^{-M})$ at order
$M$, uniformly on compact sets of saddlepoints in the closed positive orthant.

The user supplies the cumulant generating function $K$ as an ordinary Python function written
with numpy. Every derivative of $K$ that the expansions need is generated by Taylor-mode
automatic differentiation with the truncated-polynomial algebra of
{mod}`saddlepoint_expansions.taylor`, directly in the whitened coordinates in which the terms
are evaluated.

## Installation

```
pip install saddlepoint-expansions
```

The development version: `pip install git+https://github.com/s-broda/saddlepoint-expansions`.

## A first example

$X = (U_0 + U_1, U_0 + U_2)$ with independent unit exponential $U_i$, the example of Kolassa and
Li (2010), and $P(\bar X_1 \ge 3, \bar X_2 \ge 3)$ for the mean of $n = 5$ observations:

```python
import numpy as np
from saddlepoint_expansions import CGF, sample_mean, tailprob

K = CGF(lambda t: -np.log(1 - t[0]) - np.log(1 - t[1]) - np.log(1 - t[0] - t[1]), 2,
        domain=lambda t: t[0] < 1 and t[1] < 1 and t[0] + t[1] < 1)
Kn = sample_mean(K, 5)
r = tailprob(Kn, [3.0, 3.0], order=4)
r["F"]      # the expansions of orders 1 to 4
r["tau"]    # the saddlepoint
```

The exact value is $0.02215196$; the four approximations have relative errors $-3.3\%$,
$-0.04\%$, $0.01\%$ and $-1.5\times10^{-6}$.
